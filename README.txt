VIENSCO SOLAR – Design & Quote (offline web app)

HOW TO PUT IT ON PHONES
1. Upload this whole folder to any free HTTPS host (Netlify Drop: app.netlify.com/drop, GitHub Pages, Cloudflare Pages, or your own website).
2. Open the link on a phone in Chrome (Android) or Safari (iPhone).
   - Android: an "Install" bar appears automatically (or Menu > Install app).
   - iPhone: Share > Add to Home Screen.
3. After the first open it works fully offline.

Install prompts and offline mode need HTTPS (or localhost). Opening index.html straight from a file still works as a normal page.

BEFORE YOU USE IT
- Prices in the Catalogue are starting estimates – update them (More > Prices lets you shift everything by a %).
- Add your office address and bank details in More > Company details.
- Edit the default terms and warranty wording to match your policy.
- To update the app later, change the files and bump CACHE in sw.js (viensco-solar-v1 -> v2).
